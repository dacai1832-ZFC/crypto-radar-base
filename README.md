# crypto-radar-base

加密链上 Alpha 雷达的**架构与基础设施说明仓（公开展示壳）**。

> ⚠️ 本仓**不含任何可运行代码**。全部实现（采集器、判定逻辑、信源集成、
> 阈值与观察清单）位于私有仓库，不对外公开。

## 这套系统是什么

一个链上新发行代币的观察雷达：

1. **采集** —— 从公共链上数据源（节点 RPC、免费安全聚合 API）增量发现新候选池与首批 Swap 证据；
2. **影子判定** —— 在不放宽闸门、不删除历史的前提下做资格评分，输出分布与趋势；
3. **免费信源快照** —— 每日两班抓取免费社区信源做旁证（声量 / 投资情报）；
4. **晨报** —— 十板块日报经应用身份推送到即时通讯群，附 KOL 声量速览。

## 纪律（工程约定摘要）

- 采集与快照脚本**零第三方依赖**（纯标准库），CI 零安装；
- secret 只走环境变量 / GitHub Secrets，代码与日志零泄露；
- 信源缺席 ≠ 负面信号：任何来源失败都如实缺席、退出码恒 0、不谎报故障；
- 计费型信源必须有**双重预算护栏**（本地预算上限 + 远端余额感知）。
