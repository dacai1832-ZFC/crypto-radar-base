## 单班数据流

```
定时触发（每日两班）
  → 恢复状态（Release 资产下载 + 水位线）
  → Run one cycle：增量采集 → Swap 补证 → 影子判定（按钟点窗口）
  → 免费信源快照（KOL 声量 / 投资情报，缺席不报错）
  → 晨报推送（仅早班；去重窗口防重发）
  → 保存状态（Release 资产上传）
  → keepalive（周度，防调度器休眠）
```

## 关键设计决策（及为什么）

| 决策 | 理由 |
|---|---|
| 影子判定（不删候选、不覆盖历史） | 判定结论必须可回溯、可复盘，误判不能毁证据 |
| 水位线断点续跑 | 云端定时器有抖动，错过的时间片由水位线补齐，不重不漏 |
| 状态走 Release 资产 | 免服务器：Actions 运行间用仓内 Release 存状态 |
| 信源缺席恒退出 0 | 单一信源故障不炸整条管线，日报如实缺板块 |
| 判定与采集同仓私有 | 阈值、权重、观察清单是系统 edge，与代码同域保护 |
